## 一、系统概述

### 1.1 系统定位

tpl-manage 是「tpl-workspace」产品的管理后台服务端，基于 RuoYi-Vue-Plus 6.0.0 企业级快速开发平台构建。为管理员提供用户管理、角色权限、菜单配置、系统监控等核心后台管理能力。

### 1.2 核心价值

1. **快速搭建** — 基于 RVP 成熟平台，提供开箱即用的管理后台
2. **权限完善** — 细粒度权限控制：用户 → 角色 → 菜单/按钮
3. **数据安全** — PostgreSQL 存储、BCrypt 密码加密、JWT 无状态认证
4. **易于维护** — 极简自定义代码（3 个 Java 文件），核心能力继承 RVP

### 1.3 目标用户

- **超级管理员** — 系统最高权限，管理系统所有资源
- **普通管理员** — 部门或模块管理员，拥有部分管理权限
- **运营人员** — 查看操作日志、管理通知公告等日常运营操作

### 1.4 与「tpl-workspace」产品线的关系

```
tpl-manage（管理后台）
  └── 管理：用户账号、角色权限、系统配置、操作日志
  └── 为 tpl-app-api（核心业务服务）提供后台管理能力

tpl-app-api（核心业务服务）
  └── 提供：用户认证、个人中心等面向用户的功能

tpl-manage-ui（管理前端）
  └── 消费 tpl-manage 的 REST API，提供可视化后台界面
```

## 三、用户故事

### 3.1 管理员登录

- 作为管理员，我可以使用用户名和密码登录管理后台，以便访问系统管理功能
- 作为管理员，我可以退出登录以确保账号安全

### 3.2 用户管理

- 作为超级管理员，我可以创建、编辑、删除系统用户，以便管理后台使用人员
- 作为超级管理员，我可以为用户分配角色，以便控制其操作权限
- 作为超级管理员，我可以重置用户密码，以便用户忘记密码后恢复访问

### 3.3 角色权限管理

- 作为超级管理员，我可以创建角色并配置菜单权限，以便定义不同的权限组合
- 作为超级管理员，我可以设置角色的数据范围权限，以便控制其可见的数据范围

### 3.4 系统监控

- 作为管理员，我可以查看操作日志，以便追踪系统中的操作行为
- 作为管理员，我可以查看登录日志，以便监控登录异常
- 作为管理员，我可以查看在线用户并强制下线，以便管理活跃会话

## 四、非功能性需求

### 4.1 性能
- 核心 API 响应时间 < 500ms（P95）
- 支持日常管理操作（非高并发场景）
- Redis 缓存命中率 > 90%

### 4.2 安全性
- JWT 无状态认证，Token 过期自动失效
- 密码 BCrypt 加密存储
- 操作日志完整记录（操作人、时间、IP、内容）
- XSS 过滤、SQL 注入防护（继承 RVP）

### 4.3 可维护性
- 极简自定义代码（3 个 Java 文件），降低维护成本
- 依赖 RVP 成熟平台，社区活跃、文档完善
- 规范文档完整，继承 RVP 全部模块文档

### 4.4 可用性
- JWT 无状态认证，支持水平扩展
- PostgreSQL 主库 + Redis 缓存

### 4.5 兼容性
- 前端：tpl-manage-ui（Vue 3 + Element Plus）
- 数据库：PostgreSQL 15+
- 关联服务：tpl-app-api（同产品线核心服务）
